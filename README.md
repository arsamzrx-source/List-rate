# لیست ریت

## انتشار روی GitHub Pages (رایگان)
1. تو github.com یه ریپوی جدید و **Public** بساز (مثلاً `list-rate`).
2. Add file ← Upload files: **محتویات** این پوشه رو بکش (index.html، manifest.webmanifest، sw.js، آیکون‌ها، پوشهٔ audio، فایل .nojekyll و پوشهٔ fonts اگه داری). خود پوشه رو آپلود نکن.
3. Commit changes بزن.
4. Settings ← Pages ← Source: Deploy from a branch ← Branch: `main` و پوشهٔ `/ (root)` ← Save.
5. بعد از ۱ تا ۲ دقیقه آدرس `https://USERNAME.github.io/list-rate/` فعال می‌شه.
6. همین آدرس رو تو pwabuilder.com بده تا APK بسازه.
